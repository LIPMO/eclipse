À PROPOS

ECLIPSE Launcher

Le launcher ouvre le jeu dans sa propre fenêtre, sans barre de navigateur, avec les réglages de performance ci-dessus. Tout ton compte (skins, niveau, amis) est sur le serveur : rien n'est perdu si tu désinstalles le launcher.

  • Chaque version est compilée automatiquement par GitHub à partir du code public du jeu, puis accompagnée d'une attestation signée (preuve d'origine vérifiable) et de son empreinte SHA-256.
  • Les mises à jour du launcher sont téléchargées depuis la page officielle et vérifiées (empreinte SHA-512) avant d'être installées.
  • Le launcher ne contacte que le serveur du jeu et la page des versions sur GitHub (mises à jour) ; il ne lit aucun autre fichier de ton ordinateur.
  • Les fichiers Windows signés le sont gratuitement par SignPath : « Free code signing provided by SignPath.io, certificate by SignPath Foundation ».
